# LAN pre-match lobby: owner-controlled rules, guest ready, explicit start (2026-10-31)
**Scope:** user asked to make Host/Join feel like a finished game, with human-only **1v1, 0 bots**. Baseline verified signed Preview 100030, source `328707134b825eda3a105ed8faa1b1f9093096e8`; preserve [immutable rollback](https://github.com/PlayerEden/Ricochet-Rumble/tree/checkpoint/sector-rebound-preview-100030-before-lan-lobby).

**New flow:** Local Play → Host; the hosting phone starts a room without entering combat, chooses sides (FFA/1v1, co-op vs bots, opposing teams), AI 0–4, map, lives and skill. Host defaults to 1v1 with zero bots, no Solo settings overwritten. Joining phone uses Find Game or Join by IP, receives validated host rules, presses READY, and sees its ready state. Host cannot start until guest is connected and ready. Any host rule change increments the revision and resets Ready. Co-op with zero bots is invalid. START explicitly sends the revision-bound `start` command ahead of an authoritative snapshot; both players then play using existing host-authoritative combat, actors, physics and procedures. Score-based LAN CQC, vehicle FFA, and TDM are **not** in this initial LAN lobby — these need their own replicated scored protocol QA.

**Protocol:** native Java allowlists now admit host→guest `lobby,start,state`; guest→host `ready,input,interact`. Guest cannot send rules/start or arbitrary states; host cannot receive those untrusted packet types. `ready` must match exact current host revision. Stale readiness, invalid config, disconnect, or no Wi-Fi prevent launch. Guest may leave via existing disconnect. Existing rematch remains host-authoritative. TCP network never exposed to an Internet server and only runs on local Wi-Fi.

**QA required:** source smoke and native role allowlists; host no auto-start, guest receives rules, 0-bot humanCount 2, host must wait for Ready, edit resets Ready, packet version/revision, co-op requires bot, guest start gated, network disconnect fails closed, no accidental Solo settings changes. Confirm original LAN guest pilot FIRE aim, timeout, map continuity, all game UI and Android signed preview. **Two separate physical phones on same Wi-Fi still need acceptance; no remote/matchmaking claim.** Main gameplay unmerged; rollback as above.
