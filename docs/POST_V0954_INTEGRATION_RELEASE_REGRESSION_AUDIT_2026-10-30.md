No native ELF 16KB page alignment issue can be inferred for this specific archive; repeat check if native SDKs/libraries are added. Official guidance: https://developer.android.com/guide/practices/page-sizes
- **PASS (source-level safeguards):** Android manifest sets `allowBackup=false`, `usesCleartextTraffic=false` and fixes landscape; private upload and private internal TEST signing are configured by separate environment variables and explicit missing-key checks. WebView file access from file URLs/universal access is disabled; LAN packet maximum is bounded in the native wrapper. These checks are not a full penetration test.
- **P0 BLOCKED (actual release):** original CI debug APK signers can differ. The [v0.9.52 real certificate audit](ANDROID_UPDATE_PREFLIGHT_v0952.md) proved v0.9.46 and v0.9.51 cannot normally update each other in place. **No owner-held permanent TEST signer, no two same-certificate phone upgrades preserving local Dossier data and no published signed Play AAB have been verified.** `allowBackup=false` makes the validated user-directed export/restore path especially important. Android signing official: https://developer.android.com/studio/publish/app-signing
- **P0 BLOCKED (Play Console declarations):** production/closed testing requires owner-entered Data safety and privacy policy; even apps with no collection must complete the form and link a privacy policy, with internal-only testing exemption per official guidance: https://support.google.com/googleplay/android-developer/answer/10787469. Accurate age/content rating, screenshots, store icon/feature graphic, final package/ownership, Play App Signing and launch scope still require an actual Console/owner review; do not assert their present account state.
- **Conditional testing requirement:** personal Play developer accounts opened after November 13, 2023 generally require **12 opted-in closed testers for 14 continuous days** before applying for production access. Account creation date is unknown and not to be guessed. https://support.google.com/googleplay/android-developer/answer/14151465
- **Not a bug:** browser viewport screenshot tests include portrait rotations, while actual Android Manifest forces sensor-landscape; the browser portrait checks are responsive-stress evidence, not a claim the APK supports rotating portrait gameplay.
